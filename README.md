## 2. Project Structure & Dataset Overview

### Dataset Overview

- **Dataset**: Fake Bills (banknote authentication)
- **Source**: Kaggle - https://www.kaggle.com/datasets/alexandrepetit881234/fake-bills
- **Total Observations**: 1,500 rows
- **Target Variable**: `is_genuine` (True = genuine -> 1, False = fake -> 0)
- **Input Features (6)**:
  1. `diagonal` - diagonal of the bill (mm)
  2. `height_left` - height of the left side (mm)
  3. `height_right` - height of the right side (mm)
  4. `margin_low` - lower margin (mm), contains some missing values
  5. `margin_up` - upper margin (mm)
  6. `length` - length of the bill (mm)
- **File format**: semicolon-separated CSV (delimiter is auto-detected by `src/utils.py`)

## 5. Methodology

1. **EDA** (`01_eda.ipynb`): shape, missing values, class balance, distributions, boxplots, correlation heatmap.
2. **Preprocessing** (inside a scikit-learn `Pipeline`, fitted on training data only): median imputation for missing `margin_low` values, then standard scaling.
3. **Split**: stratified 80/20 train/test split.
4. **Model comparison**: Logistic Regression, KNN, SVM (RBF), Random Forest, Gradient Boosting - 5-fold stratified cross-validation.
5. **Tuning**: `GridSearchCV` on the best model.
6. **Evaluation** on the held-out test set: accuracy, precision, recall, F1, ROC-AUC, confusion matrix, ROC curve, feature importance.

## 7. Testing & Model Evaluation

The project includes unit tests for the reusable data-loading, evaluation, plotting and model-saving utilities.

### Run Automated Tests

From the root directory:

```
python -m unittest discover -s tests -v
```

The test suite verifies:

- Accuracy, Precision, Recall, F1 and ROC-AUC values
- Correct return of all evaluation metrics
- Successful execution of the confusion-matrix and ROC plotting functions
- CSV loading (semicolon delimiter, `True`/`False` target converted to 1/0)
- Pickle save/load round trip

The tests run independently, without training the model again.

### Model Evaluation Code Snippet

